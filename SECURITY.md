# Security policy

## Supported versions

The project is in development. Once released, only the latest release receives
security fixes.

## Reporting a vulnerability

Please do not open a public issue.

Use GitHub's private vulnerability reporting: open the **Security** tab of this
repository and select **Report a vulnerability**.

You can expect an acknowledgement within 7 days.

## Scope

This integration handles a personal Garmin API key. Reports about the key, the
token or personal health data being exposed (in logs, diagnostics, storage or
network traffic) are especially welcome.
